description: 변경의 인수 기준, 실행한 검사와 실기기 결과를 확인하고 증거를 정리한다.
disable-model-invocation: true
---

1. 변경 범위와 요구사항을 확인하고 [테스트 전략](../../../docs/quality/TEST-STRATEGY.md#iphone-연결-상태에-따른-검증)과 [실기기 체크리스트](../../../docs/quality/RELIABILITY-CHECKLIST.md)로 해당 커밋의 필수 실기기 항목을 정한다.
2. 저장소에 실제로 정의된 검사만 실행한다. 문서 변경만 있거나 앱이 초기화 전이면 `git diff --check`와 변경된 문서 링크를 확인하고, 앱 검사는 미실행으로 기록한다.
3. iPhone 연결 여부와 관계없이 변경에 해당하는 자동 검사를 진행한다. 위치·네트워크·권한 오류는 프로젝트에 마련된 모의 입력과 응답으로 검증할 수 있다.
4. 연결·잠금 해제된 iPhone에서는 Mobile MCP를 우선 사용한다. 기기 확인이 필요하면 [실기기 사전 확인](../../../docs/quality/RELIABILITY-CHECKLIST.md#실기기-사전-확인)을 따른다. 기기가 없거나 잠겨 있으면 필수 실기기 검사에 필요한 빌드 준비·테스트 데이터·시나리오를 먼저 갖추고, 실행 직전에 필요한 연결·잠금 해제만 사용자에게 요청한다. Mobile MCP 화면 제어가 막히면 Xcode로 설치하고 실제 iPhone에서 동작을 확인한다.
5. PR에 검증 대상 SHA, 명령, 결과와 환경을 기록한다. 실기기 필수 항목이 없으면 `실기기 해당 없음`과 근거를 남기고 일반 리뷰·CI·병합 절차를 진행한다. 필수 항목을 실행하지 못했으면 `실기기 미실행`과 사유·남은 항목을 남기고 같은 Run과 Draft에서 대기한다. 연결 후 같은 SHA에서 검증을 이어가고, 코드가 바뀌면 새 SHA에 필요한 검사와 리뷰를 다시 수행한다.

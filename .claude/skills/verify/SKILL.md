description: 변경의 인수 기준, 실행한 검사와 실기기 결과를 확인하고 증거를 정리한다.
disable-model-invocation: true
---

1. 변경 범위와 관련 요구사항을 확인하고 [테스트 전략](../../../docs/quality/TEST-STRATEGY.md), [실기기 체크리스트](../../../docs/quality/RELIABILITY-CHECKLIST.md)에서 필요한 검사를 고른다.
2. 저장소에 실제로 정의된 검사만 실행한다. 문서 변경만 있거나 앱이 초기화 전이면 `git diff --check`와 변경된 문서 링크를 확인하고, 앱 검사는 미실행으로 기록한다.
3. iPhone이 연결되지 않았거나 잠겨 있어도 가능한 로컬·CI 검사를 먼저 실행한다. 사용 가능한 iOS 런타임이 있으면 시뮬레이터 개발 빌드에서 관련 UI·탐색·오류 경로와 모의 위치를 확인한다. 런타임이나 앱 빌드가 없으면 시뮬레이터 항목의 미실행 이유를 기록한다.
4. 필수 실기기 테스트는 해당 빌드, 테스트 데이터와 시나리오가 준비된 직전에 [실기기 사전 확인](../../../docs/quality/RELIABILITY-CHECKLIST.md#실기기-사전-확인)을 따르고, 필요한 조작만 사용자에게 요청한다. 연결·잠금 해제 뒤 해당 빌드를 설치하고 실행한다. 화면 자동화가 동작하지 않으면 Xcode와 실제 조작으로 검증하고, 확인할 수 없으면 Draft에서 대기한다.
5. 명령, 결과, 환경, 검증 대상 SHA와 미실행 이유를 기록한다. 자동 검사, 시뮬레이터, 실기기 결과를 각각 기록하고 해당 SHA의 필수 실기기 검사가 미실행이면 명시한다. 실패를 보고할 때 재현 조건과 다음에 확인할 지점을 함께 적는다.

# 실기기 체크리스트

변경에 해당하는 항목을 골라 사용하고, 결과를 PR 검증란에 기록합니다. iPhone 연결이 필요한 경우 테스트 직전에 알립니다. 기록 형식: `기기·iOS·빌드 / 항목 / 결과 / 미확인`.

## 공통

- [ ] 앱을 설치하고 첫 화면까지 진입했다. (개발 빌드)
- [ ] 관련 요구사항의 핵심 경로를 기기에서 재현했다.
- [ ] 해당 기능의 빈 상태, 오류, 취소나 재시도 경로를 확인했다.
- [ ] 해당 기능에서 권한을 거부하거나 네트워크가 끊겼을 때의 동작을 확인했다.
- [ ] 저장을 사용하는 기능은 앱을 종료하고 다시 열었을 때 데이터 상태를 확인했다.
- [ ] 기기·OS·빌드, 실제 결과, 미확인 항목을 기록했다.

## 1단계 — 개인 평가·내 랭킹 (F-001~F-013, F-020, F-002, F-051)

- [ ] 처음 실행 → Apple 로그인 → 빈 내 랭킹 안내가 보인다. Google도 같은 방식으로 확인한다. 로그인 창을 취소하면 로그인 화면에서 다시 시도할 수 있다.
- [ ] 로그아웃하면 로그인 화면에 "최근에 ○○로 로그인했어요"와 해당 버튼의 "최근 사용" 표시가 나온다. 다른 수단으로 로그인하면 별도 계정이 생긴다는 안내가 보이고, 이후 최근 사용 표시가 바뀐다.
- [ ] 앱을 삭제 후 재설치했을 때 최근 로그인 기록이 남는지/없는지 확인해 기록하고, 없을 때 일반 안내가 보인다. 계정 삭제 후에는 기록이 없다.
- [ ] 로그인 상태에서 앱 종료·재실행 후에도 로그인이 유지된다. 로그아웃하면 랭킹이 보이지 않는다.
- [ ] 개발 빌드(Expo Go 아님)로 실행했다.
- [ ] 한글 검색어 입력 중(IME 조합) 요청이 매 글자 쏟아지지 않고, 입력 멈춤 후 후보가 표시된다.
- [ ] 후보 행에 이름·주소·카테고리가 보이고, **같은 이름의 다른 지점**을 구분해 선택할 수 있다.
- [ ] 키보드 `검색` 키를 누르면 전체 결과 목록이 나오고 첫 항목이 자동 선택되지 않는다. 지우기(X)로 입력과 후보가 사라진다.
- [ ] 같은 이름 체인점을 검색하면 후보가 최대 5개이고, 5개가 같은 이름이면 "지역명을 함께 입력" 안내가 보인다. 지역명을 붙이면 원하는 지점이 나온다. 이름에 `<b>` 같은 태그가 보이지 않는다.
- [ ] 지역·역 입력(예: 강남역)은 이동 행만 보이고, 확정하기 전에는 검색 기준이 바뀌지 않는다.
- [ ] 엉뚱한 문자열 → "검색 결과가 없어요". 비행기 모드 → 오류 + `다시 시도`, 해제 후 재시도 성공, 입력값 유지.
- [ ] 맛·가성비·분위기 점수 미입력 시 저장이 막히고 어느 항목인지 표시된다. 태그는 선택하지 않아도 저장된다.
- [ ] 저장 → 내 랭킹에 해당 식당이 나타난다. **앱을 완전히 종료한 뒤 다시 열어도** 같은 순위다.
- [ ] 저장 버튼 더블 탭, 저장 직후 통신 차단 → 재시도 시 평가가 1건만 있다.
- [ ] 같은 식당을 다시 평가하면 재방문 평가로 평균이 반영된다. 평가 수정·삭제 후 순위가 바로 바뀐다(재실행 후에도).
- [ ] 계정 삭제(F-002): 확인 후 삭제되고 재로그인 시 새 계정이다(이전 평가·그룹 없음). 서버 삭제가 실패(비행기 모드)하면 최근 로그인 기록이 남고 재시도 안내가 보인다. 성공하면 기록이 사라진다. 최근 재인증이 없으면 삭제가 거부되고 다시 로그인을 안내한다.
- [ ] 설정 화면에 현재 로그인 수단이 표시된다. 세션 만료(토큰 만료) 후에도 로그인 화면에 최근 사용 표시가 보인다.

## 1b단계 — 카카오·네이버 로그인 (F-050)

- [ ] 카카오 로그인 성공·취소·실패(이메일 미동의 포함)가 각각 동작하고 랭킹 탭으로 진입한다.
- [ ] 네이버 로그인도 동일하게 동작한다. 로그아웃 후 로그인 화면의 "최근 사용"이 바뀐다.
- [ ] 4개 수단 모두 계정 삭제 후 다시 로그인하면 새 계정이다(이전 평가 없음).
- [ ] 같은 이메일을 쓰는 Google·카카오 계정으로 각각 로그인하면 **별도 계정**이다(평가가 공유되지 않음).

## 2단계 — 그룹 (F-021~F-024, F-030~F-035) *계정 2개 필요*

- [ ] 그룹 만들기 → 초대 링크 공유 → 두 번째 계정이 링크로 참여한다. 커플(2인) 그룹에 세 번째 사람은 정원 초과 문구가 나온다.
- [ ] 만료·폐기된 링크, 이미 멤버인 계정의 링크가 각각 구분된 안내를 보여 준다. 로그아웃 상태에서 링크를 열면 로그인 후 이어서 참여한다.
- [ ] 같은 식당을 두 계정이 각각 그룹으로 평가 → 두 기기의 그룹 랭킹 순위·점수가 같다.
- [ ] 그룹 A와 B 모두 같은 식당을 평가했을 때 A 랭킹에 B의 평가가 섞이지 않는다.
- [ ] 랭킹 상단에 현재 범위(내 랭킹/그룹 이름)가 항상 보이고, 범위를 바꾸면 이전 항목이 남지 않는다.
- [ ] 비멤버 계정으로 그룹 화면·랭킹에 접근할 수 없다. 그룹을 나간 계정이 즉시 접근 불가이고 나간 멤버의 그룹 평가가 그룹 랭킹에서 빠진다.
- [ ] 유일한 관리자가 나가거나 계정을 삭제하면 가장 오래된 멤버가 관리자를 승계하고, 마지막 멤버가 삭제하면 그룹이 사라진다.
- [ ] 멤버가 만든 초대 링크를 생성자가 목록에서 보고 폐기할 수 있고, 생성자가 그룹을 나가거나 계정을 삭제하면 그 링크가 무효가 된다. 링크의 토큰 문자열을 붙여넣어도 참여된다.

## 3단계 — 방문 인증 (F-040~F-044)

- [ ] 첫 앱 실행·로그인·검색에서 **위치 권한 팝업이 뜨지 않는다.** 첫 평가 저장 때 안내 후 권한을 요청한다. 한국어 사용 목적 문구가 맞다.
- [ ] 식당 앞에서 저장 → '방문 인증' 배지. 안내 문구가 "이 평가를 남길 때 식당 근처에 있었어요"의 의미를 전달한다.
- [ ] 식당에서 약 300m 이상 떨어져 저장 → 배지 없이 저장, 사유가 구분되어 안내된다. (199/200/201m 경계는 자동 테스트로 검증; GPS 오차로 실기기 재현 불가임을 기록)
- [ ] 위치 권한 거부 / 위치 서비스 끄기 / 정확한 위치 끄기(대략적 위치) / 실내(낮은 정확도) 각각에서 평가는 저장되고 배지만 없다. 거부 후 반복 팝업이 없다.
- [ ] 같은 사용자의 인증된 평가와 미인증 평가가 각각 올바르게 표시된다. 그룹원의 화면(두 번째 계정)에 배지 정보가 노출되지 않는다.
- [ ] 백그라운드에서 위치 사용 표시(상단 파란 표시)가 남지 않는다. 설정 앱의 위치 권한이 "앱을 사용하는 동안"뿐이다.
- [ ] 서버 저장 데이터(관리 화면)에 좌표 열·값이 없다.

## 4단계 — 지도 (F-005 지도, F-007, F-009, F-025)

- [ ] 입력 중에는 지도가 움직이지 않고, 확정 후에만 이동·클로즈업한다.
- [ ] Focus 모드에서 지도 드래그·확대로 결과가 바뀌지 않으며 지우기(X)·검색어 편집·뒤로 제스처로 해제된다.
- [ ] 선택 식당 핀이 올바른 위치에 표시된다. 지도 로딩 실패(비행기 모드)에도 목록·평가 저장이 동작하고 `다시 시도`가 보인다.
- [ ] 랭킹의 "지도로 보기"가 현재 범위의 식당만 핀+순위로 보여 준다. 내 랭킹 ↔ 그룹A ↔ 그룹B 전환 시 이전 핀이 남지 않는다. 지도에 현재 위치 표시·위치 권한 팝업이 뜨지 않는다.

## Android 스모크 (범위 확정 후)

- [ ] 빌드·설치, 로그인, 검색 → 평가 저장 → 내 랭킹이 동작한다. 위치 권한 거부 경로가 동작한다.

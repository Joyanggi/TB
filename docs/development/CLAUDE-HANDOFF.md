# Claude Code에 붙여넣을 시작 요청문

앱 아이디어가 정해지면 아래 코드 블록을 Orca에서 이 저장소를 연 Claude Code에 붙여넣습니다. 앱을 한두 문장으로만 설명해도 시작할 수 있습니다.

```text
이 저장소를 첫 모바일 앱 프로젝트로 준비해줘.

만들 앱: [앱 아이디어를 한두 문장으로]
주 사용자와 해결할 문제: [아는 만큼]
첫 버전에 꼭 필요한 기능: [아는 만큼]
제약 또는 참고: [예산, 일정, 유사 앱, 원하는 화면이나 플랫폼 등. 없으면 비워둠]

1. README.md, CLAUDE.md, AGENTS.md와 docs/를 먼저 읽어줘. 내가 준 내용을 바탕으로 핵심 사용자, 첫 실행부터 목표 달성까지의 흐름, 첫 버전 범위를 정리해줘. 제품 방향을 바꾸는 미결정 사항만 묻고 합리적인 초안은 제안으로 표시해줘.
2. docs/product/PRD.md와 REQUIREMENTS.md에 합의한 요구를 채워줘. 핵심 기능별 인수 기준과 필요한 오류 경로를 적고, 미정인 부분은 이유와 함께 남겨줘.
3. Orca Mac 로컬에서 Expo, React Native, TypeScript로 개발하고 iPhone을 먼저 검증한다는 기준으로 ARCHITECTURE.md를 채워줘. iOS·Android 출시 범위, 앱 이름과 식별자, 저장 방식, 서버·로그인·권한 필요 여부를 정리해줘. 중요한 기술 결정을 내리면 docs/decisions/에 근거를 남겨줘.
4. TEST-STRATEGY.md, RISK-REGISTER.md, RELIABILITY-CHECKLIST.md를 이 앱에 맞게 채워줘. 핵심 흐름의 정상·실패 경로와 실기기에서 확인할 결과를 정리해줘.
5. 문서 초안이 준비되면 첫 버전 범위, 미정 사항, 첫 구현 작업과 확인 기준을 내게 먼저 보여줘. 여기까지는 기획·설계 작업이야. 내가 진행하라고 하면 호환되는 도구 버전을 공식 문서와 로컬 환경에서 확인하고 이 저장소에 Expo 앱을 초기화해줘.
6. 초기화 후 README와 /verify에 실제 실행해 본 명령을 기록해줘. 첫 실기기 빌드 직전에 iPhone 연결을 알려줘. 이후에는 작은 기능 단위로 구현하고, 관련 검사와 실제 확인 결과를 남긴 뒤 별도 리뷰 세션에 diff와 검증 근거를 넘겨줘.
```
